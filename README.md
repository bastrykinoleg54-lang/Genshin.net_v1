# Локальный сайт и отчёты сессий

## Запуск

Откройте PowerShell в этой папке и выполните:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start-server.ps1
```

Откройте `http://localhost:4173/`. Чтобы завершить текущий цикл, нажмите `Ctrl+C` в том же окне PowerShell. После остановки итоговый отчёт находится в папке `Журналы сервера`; для каждого запуска создаётся отдельный Markdown-файл.

Отчёт фиксирует посещённые страницы, нажатия на кнопки и ссылки, изменения фильтра и отправку/результат демонстрационных форм авторизации. Пароли, адреса электронной почты, содержимое полей и текст поисковых запросов не записываются.

Авторизация сайта — демонстрационная: регистрация и вход сохраняют состояние только в браузере и не создают серверную учётную запись. Журнал подтверждает действия интерфейса, но не проверяет личность пользователя.
